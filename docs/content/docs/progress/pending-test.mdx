# Pending Tests

The current release needs manual verification in these areas:

- Intent-driven generation and connection semantics: verify that existing `input` connections remain intact, generated results add only `lineage` connections, and `repeat`, `derive`, `retry`, and `resume` each use the intended request inputs.
- Concurrent jobs & cancellation: cancel one job while others continue independently; after `GET /queue`, confirm a queued target is deleted with `POST /queue`, while `/interrupt` is used only when that exact target is running.
- Fail-loud validation: invalid model/Frame inputs, and an empty generation result, should each surface an explicit localized error instead of failing silently or leaving the node in a broken state.
- Stable `@[node:id]` references: `@[node:id]` tokens should stay stable across edits, refresh, and re-referencing without duplicating or reordering the underlying connection.
- Agent invalid connections: the canvas Agent should reject missing-node, self, Config-source, Group-target, and duplicate connections, leaving no invalid edge in the snapshot.
- Nested groups: groups nested inside groups should collapse, expand, reference, and generate correctly, including when the inner and outer group are referenced by the same generation node.
- Source media status: when a generation derived from a successful image/video/audio/text node fails, the source node should keep its original content and `success` status.
- Audio generation entry: the audio generation entry point is hidden, while audio assets still upload, connect, and act as reference media normally.

- User Manual & ComfyUI Workflow Downloads Page (/guide):
  - **Comprehensive 6-Workflow Coverage**: Built-in cards and JSON downloads for all 6 core workflows (Z-Image-Turbo T2I, Flux2.Dev I2I, Qwen Inpaint, Qwen 3.5 LLM, MiniMax H3 FL2V, and MiniMax H3 Ref2V).
  - **One-click ZIP Packager**: Bundles all 6 workflow JSONs and a structured `README_模型与存放目录清单.txt` with fflate for client-side offline saving.
  - **Local Model Directory Checklist**: Exact folder paths (`models/diffusion_models/`, `models/vae/`, `models/text_encoders/`, `models/loras/`) with one-click copy buttons for both individual filenames and entire path checklists.
  - **ComfyUI Connectivity Probe & Launch Command**: Real-time diagnostic ping to the user's configured ComfyUI IP & port (from config store, falling back to default 8188) with `--enable-cors-header "*"` guidance and one-click copyable typical launch command (`python.exe main.py --listen 0.0.0.0 --enable-manager --enable-cors-header "*"`).
  - **Global Seamless Navigation**: Dedicated links from top navigation bar (replacing external doc link), mobile navigation drawer, home page hero section, and config page header banner.

- Fix Configuration & User Preferences Refresh Mutation Bug:
  - **Symmetric Workflows & Default Fallbacks**: Added `comfyuiT2iWorkflow` to `ModelChannel` and passed `defaultWorkflow={DEFAULT_COMFYUI_*_WORKFLOW}` to all 6 workflow editors, preventing workflow status flips (Built-in / Custom / Unassigned) and revert issues on browser reload.
  - **Safe Model Preference Persistence**: Added capability-aware fallback during `merge` for `imageModel`, `videoModel`, and `textModel`, ensuring that obsolete or unselected values never wipe settings to empty strings.
  - **Atomic Save & Storage Version Migration**: Introduced `setConfig` for atomic single-pass persistence to `localStorage` and bumped storage `version: 1` to cleanly isolate legacy data.

- ComfyUI Video Output Download 404 Fix:
  - **Retain Subfolder Parameter**: Preserves full query parameters (`/api/view?filename=xxx.mp4&type=output&subfolder=video`) when ComfyUI returns a `subfolder` field (such as `video`), preventing 404 errors caused by dropping `subfolder`.
  - **Video Extension Detection**: Automatically classifies video files (`.mp4`, `.webm`) even when returned inside the `images` output list by custom nodes.
  - **Dual Endpoint Fallback**: Supports both `/api/view` and `/view` endpoints with automatic fallback on 404.

- System Built-in ComfyUI Workflows & Custom Binding Management:
  - **Built-in Default Bindings**: The 6 standard API workflows from `comfyui_api` (`comfyuiT2iWorkflow_api.json`, `comfyuiI2iWorkflow_api.json`, `comfyuiInpaintWorkflow_api.json`, `comfyuiTextWorkflow_api.json`, `comfyuiVideoWorkflow_api.json`, `comfyuiFrameVideoWorkflow_api.json`) are built directly into the system for out-of-the-box operation.
  - **Custom Workflow Indicator & Reset**: Workflow cards in the channel editor drawer show clear "Built-in" (系统内置) or "Custom" (自定义) tags with file size. When a custom workflow is uploaded, users can click "Reset to Default" (恢复默认) to return to the built-in workflow, or clear it.
  - **Execution Fallback**: Generation for T2I, I2I, Inpaint, Text inversion, and Video automatically falls back to system defaults if no custom workflow is uploaded.

- Video Node "Omni Reference" & "Frame Video" Strict Isolation & Two-way Sync:
  - **Bi-directional State Sync**: Toggling between "Omni (全能参考)" and "Frame (首尾帧)" in the video settings popover automatically updates the ModelPicker to `ComfyUI Video` or `ComfyUI Frame Video` respectively, and vice versa.
  - **Strict Workflow Routing**: "Omni" mode strictly invokes `comfyuiVideoWorkflow`, while "Frame" mode strictly invokes `comfyuiFrameVideoWorkflow` without cross-fallback confusion.
- Full Modal Nodes (Text, Image, Inpaint, Video) Support "Query Again":
  - **Real-time jobId Persistence**: Once submitted to ComfyUI `/prompt`, the returned `jobId` is immediately recorded into the node metadata and saved locally.
  - **Interruption Recovery**: Whether reset on page reload or timed out, any node with an existing `jobId` shows "Query again" (重新查询) on both card and toolbar.
  - **Zero Waste Polling**: Clicking "Query again" directly queries `/history/{jobId}` without resubmission or duplicating GPU computation. If no `jobId` exists, it stays "Retry" (重新生成).
- Channel Editor Drawer Simplification: Removed the redundant bottom "Provider Models" list module. All capabilities and workflows are now directly managed and uploaded via the dedicated workflow cards (T2I, I2I, Inpaint, LLM, Video, Frame Video), making the interface clean and straightforward.
- Direct Connection to Native ComfyUI 8188 API:
  - **Default URL & Auth**: Channel management default URL is updated to `http://127.0.0.1:8188`. Token is now optional to seamlessly support standard local unauthenticated ComfyUI instances.
  - **Native Endpoints**:
    - Asset Uploads: Directly calls `POST /upload/image` with FormData into the ComfyUI `input` folder, binding plain file names to node inputs.
    - Workflow Submission: Directly calls `POST /prompt` with `{ prompt, client_id }`, handling `node_errors` validations immediately.
    - Job Polling & Outputs: Directly polls `GET /history/{prompt_id}` and extracts `images`, `videos`, `gifs`, `audio`, and `text` output channels.
    - Asset Viewing & Downloads: Directly calls `GET /view?filename=xxx&type=output` to render images/videos.
    - Cancellation: Reads active jobs via `GET /queue`, deletes a queued target with `POST /queue`, and calls `POST /interrupt` only when that exact target is running.
- Video Node & Workflow Omni Reference vs First/Last Frame Dual Modes:
  - **Channel Workflows**: Channel configuration independently separates "Video Generation Workflow (Video / Omni)" and "First & Last Frame Video Workflow (Frame Video)", with default models `ComfyUI Video` and `ComfyUI Frame Video`.
  - **Mode Switch**: Video settings panel and canvas popover button support instant toggling between "Omni Reference (Omni)" and "First / Last Frame (Frame)".
  - **Omni Reference Mode**: Supports up to 9 images, 3 videos, and 3 audios with auto routing to `ref_image_01..09` / `ref_video_01..03` / `ref_audio_01..03` and automatic unassigned branch pruning.
  - **First & Last Frame Mode**: The first connected image is assigned to `first_frame`, and the second connected image to `last_frame`. If only 1 image is connected, the unassigned `last_frame` node is cleanly pruned, enabling single-image start frame video generation or dual-image start-to-end interpolation video generation.
- Separate T2I and I2I Workflow Management: In Channel Management outer card and drawer, "Text-to-Image Workflow (T2I)" and "Image-to-Image Workflow (I2I)" are presented as independent upload cards, with default models `ComfyUI T2I` and `ComfyUI I2I`. When generating purely from text prompts on canvas, the system invokes the T2I workflow; when connecting reference images (single-image edit, style transfer, dual-image fusion), it automatically routes to the I2I workflow.
- Flux2 Image Editing & Dual-Image Fusion Pipeline: Supports image editing and multi-image blending (up to 2 reference images) based on the Flux2 workflow (`image_flux2_fp8_api.json`). When connecting 2 images on the canvas, they are automatically uploaded and mapped to `ref_image_01` and `ref_image_02` slots. When connecting 1 image, unassigned `ref_image_02` branches and intermediate scaler/encoder nodes are pruned while `ReferenceLatent` cascades are dynamically bridged to the first reference latent. When generating with 0 images, all ReferenceLatent nodes are cleanly bypassed to FluxGuidance with scheduler dimensions rewired for pure text-to-image.
- Video generation resume polling on timeout: When a video job is successfully submitted to ComfyUI, the system records and persists its `jobId` in node metadata. If a timeout occurs due to slow local GPU rendering or queueing, the node enters an error state with its `jobId` preserved, and the action button on both card and hover toolbar turns into "Check status again". Clicking it resumes polling the existing `jobId` without re-submitting or wasting GPU cycles.
- Video duration 5-15s slider & quick presets: In video settings panel and popover, duration can now be adjusted smoothly via a 5s to 15s continuous slider with tooltip formatting, alongside three quick-select pill buttons for 5s, 10s, and 15s. The title dynamically reflects the current second value with bi-directional synchronization, injecting precisely into workflow duration calculation nodes.
- ComfyUI 2-hour job timeout window: The global polling timeout for asynchronous ComfyUI jobs has been raised from 10 minutes to 2 hours (7,200s), ensuring heavy video diffusion models, long-step samplers, and queued execution on local GPUs are not prematurely aborted; error messages now format duration cleanly (e.g. `after 2h`).
- Multimodal reference video generation pipeline: Supports connecting up to 9 image nodes, 3 video nodes, and 3 audio nodes to generation config or video nodes on canvas. The system automatically uploads references via the native ComfyUI upload endpoint and routes them in FIFO connection order to `ref_image_01..09`, `ref_video_01..03`, and `ref_audio_01..03` slots. Unassigned slots and their intermediate bridge nodes (e.g. `GetVideoComponents`) are pruned completely from the workflow JSON with incoming references removed from the main node to ensure smooth text-to-video or arbitrary reference count execution. Fails loud with explicit errors if user connects inputs exceeding slot limits.
- MiniMax video size presets: The video generation settings panel replaces free-form W/H inputs with strict 16:9 landscape and 9:16 portrait ratios, locking resolution into 9 discrete presets from 0.2M to 0.98M (up to 1344x768 / 768x1344). Preset cards directly display exact pixel width and height with secondary tier tags, dynamically swapping dimensions when toggling aspect ratios and injecting into workflow nodes.
- ComfyUI video generation & unified workflow group: In Channel Management outer card and edit drawer, all ComfyUI workflows (Text-to-Image T2I, Inpaint, LLM Text/Reverse, and Video) are unified in the same workflow group with dedicated upload and clear controls. Added ComfyUI Video as a pre-provisioned model and default video model, and video generation in canvas/workbench now executes via ComfyUI.
- ComfyUI LLM text generation & visual reverse prompt: The channel settings include a default ComfyUI LLM model and a dedicated "Text Generation / Reverse Prompt Workflow (LLM)" upload card, bundled with the Qwen 3.5 VLM workflow. Clicking "Reverse prompt" on an image node and generating should upload the image via the native ComfyUI upload endpoint into the `image` node, inject instructions into the `prompt` node, and output the reversed prompt to a new text node. When generating without an image, it automatically strips the `_meta.title=image` node and its input links for text-to-text execution.
- ComfyUI inpaint workflow: In Channel Management for ComfyUI, a dedicated "Inpaint Workflow" upload entry should be visible, allowing users to upload and persist the inpaint workflow JSON. Default model list includes ComfyUI Inpaint. When painting a mask on an image and clicking "Edit with AI", the base image and mask should automatically upload via the native ComfyUI upload endpoint, inject into `ref_image` and `ref_mask` slots, submit, and download the edited image.
- Direct raw text replacement in prompt assembly: When referencing a text node via @ in a config node or prompt input, the submitted prompt should directly replace the reference with the text node's raw content, without adding [Text 1] tags, numbering, or append blocks.
- ComfyUI-only channels: The channel system has been simplified to exclusively support local ComfyUI channels, removing OpenAI, Gemini, and other external LLM API endpoints. The channel editor displays only the ComfyUI URL and optional access token, and defaults to ComfyUI T2I. All canvas interactions, asset uploads, and node operations are preserved.

- Video frame capture: right-clicking a video node with content should show Capture first frame, Capture last frame, and Capture current frame.
