# 官网演示视频放置规范 (Website Demo Video)

本目录为官网 Hero 演示视频的预留目录。

## 文件规范
- **默认视频文件路径**：`website/assets/videos/demo.mp4`
- **建议格式**：`MP4 (H.264 / AAC)`
- **建议比例**：`16:9`（例如 1920×1080 或 2560×1440）
- **建议时长**：`30秒 ~ 60秒`
- **建议容量**：压缩在 `15MB` 以内，保障首屏快速加载。

## 自动生效机制
1. 当本目录下未放置 `demo.mp4` 时：
   - 官网将自动呈现高保真科技感画布动态模拟器，点击播放会弹出友好的替换指引提示。
2. 当您将录制好的演示视频保存为 `demo.mp4` 并放置于本目录后：
   - 官网会自动识别并无缝切换为真实视频播放与画中画模式。
