# 官网演示视频放置规范 (Website Demo Video)

本目录为官网 Hero 演示视频的预留目录。

## 文件规范
- **默认视频文件路径**：`website/public/videos/demo.mp4`（在网页中通过 `/videos/demo.mp4` 直接访问）
- **建议格式**：`MP4 (H.264 / AAC)`
- **建议比例**：`16:9`（例如 1920×1080）
- **建议时长**：`30秒 ~ 60秒`
- **建议容量**：压缩在 `15MB` 以内。

## 自动生效机制
1. 当本目录下未放置 `demo.mp4` 时：
   - 官网将呈现高保真科技感画布动态背景，点击播放按钮弹出替换指引弹窗。
2. 当放置录制好的 `demo.mp4` 后：
   - 官网将自动切换为真实视频高清播放。
