FAQ

Good to know.

What do I need to run infinite-canvas?

A running ComfyUI instance (default at 127.0.0.1:8188) with the --enable-cors-header flag enabled. Node.js 18+ or Bun 1.1+ for local web dev.

Where do my credentials and data go?

Your canvas topologies and configurations stay on your machine's browser IndexedDB. Generations are stored in ComfyUI's output folder. No external cloud servers.

How do I fix CORS errors?

Start ComfyUI with: python main.py --listen 127.0.0.1 --port 8188 --enable-cors-header.

How many references are supported for Multimodal Video?

Up to 9 images + 3 videos + 3 audio streams with hardware locked resolution between 0.2M and 0.98M.
